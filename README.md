# Campus Grievance & Maintenance Portal

A web-based **College Grievance & Maintenance Management System** developed to help students submit complaints online and allow administrators to efficiently manage, track, and resolve those complaints.

## 🌐 Live Website

**Live Demo:** https://campusgrievance.rf.gd/

> Note: The live website is hosted for demonstration purposes.

---

## 📌 Project Overview

The Campus Grievance & Maintenance Portal provides a centralized platform where students can report college-related issues such as maintenance problems, infrastructure concerns, cleanliness issues, and other campus grievances.

The system provides separate interfaces for **Students** and **Administrators**, making the complaint process more organized, transparent, and easier to manage.

---

## 🎯 Objectives

- Provide students with an easy way to submit complaints online.
- Generate and manage complaint records digitally.
- Allow students to track the status of their complaints.
- Help administrators manage students and complaints from one dashboard.
- Reduce dependency on manual complaint registers.
- Improve transparency in the grievance resolution process.

## 💻 Local Development

This project was developed and tested using **XAMPP** with PHP and MySQL.

For local development:

1. Install XAMPP.
2. Start **Apache** and **MySQL**.
3. Place the project inside the XAMPP `htdocs` directory.
4. Create/configure the required MySQL database.
5. Add your local database configuration separately.
6. Open the project through the local Apache server.

Example:

```text
http://localhost/Campus-Grievance-Maintenance-Portal/
```
